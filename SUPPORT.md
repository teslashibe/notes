# Support

Use GitHub issues for reproducible bugs and focused feature requests. Include
the Go version, macOS version when relevant, the operation attempted, and a
minimal reproduction with all note content and identifiers removed.

This community project does not provide guaranteed response times. Questions
about Apple account access, Notes data recovery, macOS privacy permissions, or
code-signing identities should be directed to Apple support or the appropriate
platform administrator.

Report security concerns privately as described in [SECURITY.md](SECURITY.md).
